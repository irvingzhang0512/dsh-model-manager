## 尚未达到需求的部分

- 宿主当前 `GenerateOptions` 只有 `reasoningEffort`，没有独立 Thinking 开关；Thinking Off 冲突校验无法按原方案实现。
- `region` 当前作为视觉问题提示，不做像素裁剪；视觉缓存仅内存保存，未持久化，也未按图片内容哈希去重。
- 主 Agent 提示词接口已注入有效角色说明，但角色是否被恰当地选择仍需真实任务验收。
- 参数降级开关尚未实现运行时降级；长上下文专用候选、历史图片切换保护未完成。
- 日志有会话、逻辑/实际模型、尝试、路由、耗时、状态、可用 Token 用量和 Provider 请求 ID；尚未关联每轮与插件自己的请求 ID，也未覆盖所有失败详情。
- 批量验证、可取消的验证队列、自动显示证据过期状态尚未实现。
- GUI 端到端视觉、角色委派、原生图片编辑与回归验收未完成，因此不得填写 `verifiedWith` 或更新安装快照。
