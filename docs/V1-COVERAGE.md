## 尚未达到需求的部分

- 宿主当前 `GenerateOptions` 只有 `reasoningEffort`，没有独立 Thinking 开关；插件把关闭映射到模型公开的实际 `off` 档位，并做冲突校验，但不能提供独立于 Reasoning 的思考开关。
- 档位自动推断按已知档位 id 排序（off/minimal/low/medium/high/xhigh/max），未知 id 排在其后按字母序；对非标准命名的 Provider 可能推断失当，需在别名卡中显式覆盖。
- `region` 使用归一化 `x,y,width,height` 执行像素裁剪，裁剪件单独保存，原图仍保留在宿主附件中；视觉缓存已按图片内容哈希和配置版本隔离并持久化，但重启后的会话附件引用恢复仍待真实验证。
- 主 Agent 提示词接口已注入有效角色说明；按明确指令的角色委派已通过，复杂任务中的自主角色选择仍需真实验收。
- 参数降级仅在策略开启、拒绝信息明确指向推理参数且用户没有覆盖锁定时执行一次，待真实故障验收。上下文溢出只走内置别名 @long-context 的候选（别名删除时溢出直接失败）；历史图片关闭视觉后可转文字引用继续，但两者仍需真实故障与会话验收。
- 受管理主模型日志有会话、轮次、插件请求 ID、逻辑/实际模型、尝试、路由、耗时、状态、可用 Token 用量和 Provider 请求 ID；非托管子 Agent 与视觉调用的轮次关联、全部失败详情仍不完整。
- AI 推荐分工每次消耗一次主模型请求；推荐质量依赖模型目录声明与验证证据的完整性。
- AI 探测只覆盖图片与工具能力：上下文容量、最大输出、推理档位无法由单次请求证实，仍需手工填写或依赖宿主元数据；探测请求为真实计费调用，批量探测的中断恢复与宿主写入冲突场景待真实 GUI 验收。声明临时提权实测有几秒的宿主配置变更窗口，进程若在窗口内崩溃，宿主声明可能停留在「支持」。
- v2 GUI 回归（模型分组折叠、验证建议一键写入、AI 推荐弹窗、别名卡内档位映射与别名级兜底覆盖、旧配置迁移后的设置页显示）未完成，因此不得填写 `verifiedWith` 或更新安装快照。
