# 更新记录

## 未发布

- 探测结果全部改为居中弹出框，探测路径不再使用右下角 toast（自动消失来不及看）：单模型探测无结论时弹出证据详情（原 toast 一闪而过）、探测失败弹出失败原因、批量探测总结与恢复失败模型名单进弹出框、建议「应用选中项」后弹出框内直接转为「已应用」状态确认，不再关闭后依赖 toast。
- 模型选择统一到宿主原生选择器：受管理 Provider 只列 `AUTO` 与 `@别名` 两种条目，不再逐个重复列出原生模型（具体模型直接选原生条目即可）。`AUTO` = 托管入口，主模型按 Manual/Auto 方案解析（配了目标用目标，没配回退宿主默认模型 `agent-default-model`）。
- 模式（手动/自动）升级为托管总开关：手动 = 主模型跟随原生选择、不启用分发；自动 = 托管，按 Auto 行决定主模型并启用子 Agent 角色分发（委派工具与系统提示只在自动模式生效）。子 Agent 角色卡移除逐角色「启用」勾选——绑定模型即代表参与分发，角色目标在使用时校验，不再阻塞配置保存。
- 删除对话输入框左下角的「模型管理 · 手动/自动」折叠控件：模型选择统一走原生选择器，配置统一走设置页；会话级临时覆盖的后端接口保留（暂无界面）。

- 设置页讲解与排版系统化补齐：页头新增「插件定位 / 推荐配置顺序 / 配好后聊天界面会看到什么」引导卡；「模型」「可靠性」「验证」页新增「这一页是干什么的」说明卡，「日志」页补调用记录说明（记录什么、保留多久、如何核对实际模型）；说明卡与操作卡视觉分层（浅底引导样式 `.dmm-guide`）；Manual/Auto 的 manual/auto 两行拆为独立卡片并给全部字段加中文标签，子 Agent 角色行加「目标/思考/档位」标签且 main 行控件整体禁用（SelectModel/ThinkingSelect 支持 disabled）。
- 三处「看不懂」的界面讲解补全：输入框「模型管理」控件展开后加用途说明、控件分两行（选择行 + 范围/操作行）、范围选项改为「仅下一条消息 / 本会话一直有效」、折叠标题的模式显示中文化（手动/自动）并加浮层样式；「别名与推理配置」与「Manual/Auto」页各加「这一页是干什么的」说明卡（别名与档位映射在哪被引用、Manual/Auto 只对走模型管理入口的会话生效、临时覆盖优先级）；「Auto 子 Agent 角色」更名「子 Agent 角色（委派分工）」，main 行复选框禁用并说明不参与委派。
- 视觉配置页重写为讲解式布局：新增「视觉辅助是做什么的」说明卡（默认行为与开启后的两条看图路径）、「看图工具的工作方式」说明卡（文字占位、裁剪区域、结果缓存）；「策略」下拉改为中文选项（原生优先/看图工具优先/仅原生直读/仅看图工具）并随选中项动态显示取舍说明；「视觉模型」说明何时被用到、留空回退到 vision 角色绑定、何时可以留空。配置值与行为不变，纯文案与展示调整。
- 测试池从 forks 固定为 threads（新增 `vitest.config.ts`）：forks 池依赖 IPC 命名管道，在受限执行环境里 spawn worker 会 EPERM；threads 池不依赖命名管道，各环境均可运行。
- 删除工具探测与「插件工具声明」：该字段在插件内无任何消费点、宿主目录也从不提供工具声明，属于纯记录；探测固定只发一次真实图片请求，卡片不再显示「工具：」，建议对话框不再出现「插件工具声明」。「验证」标签的工具验证类型保留。
- 修复：点「保存设置」后整页白屏——保存接口响应缺少 `verifications` 字段，客户端用响应整体替换渲染状态后在模型卡片渲染 `undefined.filter` 崩溃；现在保存接口返回完整快照，客户端对所有快照响应做字段归一化兜底，并为设置面板与输入区控件加了错误边界（渲染异常显示可重试的错误卡片，不再白屏）。
- 模型页反馈重构：所有操作结果改为右下角浮动提示（toast），不再只显示在页面底部；「刷新目录」增加进行中状态与数量变化说明（新增/移除/无变化）。
- 模型页筛选增强：Provider 下拉与模型名/ID 文本框组合过滤，显示「匹配 M / 共 N 个模型」，无匹配时给出空状态与「清除筛选」；筛选范围同时作用于批量验证。
- 新增 AI 能力探测：`POST /api/model-manager/probe` 对模型串行发出真实图片与工具探测请求，`probeSuggestions` 把行为证据映射为可写入建议（含置信度与依据）；面板提供单模型探测（带建议预览与逐项确认）与批量探测（只自动写入高置信结论，显示进度）。
- 探测支持「声明不支持但实际支持」的模型：宿主会把发送前的图片按声明替换成文字占位，导致此类模型永远探测为「未观察到」；现在探测时先把宿主 input 声明临时提为支持实测，无论成败都恢复原声明，恢复失败会明确警告。
- 探测建议预览改为居中模态对话框（原页面顶部卡片在长列表中不可见）；补充提权说明、探测说明与恢复失败警告的展示。
- 底部操作条固定在面板底部并显示脏状态：有未保存修改时提示「● 有未保存的修改」，「保存设置」在无修改时禁用，「重新加载」在有未保存修改时先确认；补充「保存设置」与「保存到宿主」的区别说明。
- 修复：模型卡片「保存到宿主」成功后不再重置配置草稿（此前会静默丢弃未保存的插件配置修改）。
