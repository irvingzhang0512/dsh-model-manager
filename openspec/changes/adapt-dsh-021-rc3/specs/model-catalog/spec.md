# Spec Delta

## ADDED Requirements

### Requirement: RC3 官方运行目录与持久覆盖分开

管理器 SHALL 使用目标宿主公开模型目录呈现官方动态型号，区分原始用户覆盖、继承配置和内置默认。读取、取消和失败不得把运行或内置默认目录自动持久化；已有用户模型列表、未知字段及有效引用保留。

#### Scenario: 无用户目录覆盖时官方目录新增型号
- **WHEN** 宿主运行目录含新型号而设置 effective 仍为内置目录
- **THEN** 读取和预览使用运行目录，不新增用户 models，编辑按现有预览及完整写集保存

#### Scenario: 旧默认或自定义列表已经保存
- **WHEN** 用户层或继承配置包含显式模型列表
- **THEN** 保留列表和用户字段，不因升级自动恢复默认；取消、冲突及失败不改持久配置
