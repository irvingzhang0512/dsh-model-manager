# F005 DSH 原生 Subagent 设置

## Purpose

为 dsh-model-manager 的DSH 原生 Subagent 设置维护唯一可编辑的行为与验收规格，保留原编号 F005，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## Requirements

### Requirement: F005 DSH 原生 Subagent 设置

系统 SHALL 按下列完整场景落实DSH 原生 Subagent 设置的预期、边界与验收。本节迁入已有功能规则；本次仅迁移文档，没有重新执行产品验收。

#### Scenario: F005-S01 Desktop 契约

- **WHEN** 用户使用原生子任务或处理旧分工偏好
- **THEN** Desktop 契约：原生拆分／显式子模型／fork 继承继续独立于 AUTO；不恢复插件子任务配置页或旧偏好。范围与引用按当前宿主公开契约定位，不硬编码旧 subagent-model-selection 分节；见 Desktop 契约第 5、8 节。

#### Scenario: F005-S02 保留 F005 编号记录移除范围

- **WHEN** 用户使用原生子任务或处理旧分工偏好
- **THEN** 保留 F005 编号记录移除范围：删除插件“子 Agent”标签页、原生范围编辑入口与分工偏好新增／编辑功能；子任务模型范围统一在 DSH 官方设置配置。插件不再提供该范围的独立读写路由，但保留原生运行兼容和目录操作的引用处理。

#### Scenario: F005-S03 历史配置

- **WHEN** 用户使用原生子任务或处理旧分工偏好
- **THEN** 历史配置：auto.preferences 改为可选停用字段；显式存在则原样保留，缺失不补默认值，v1／v2 旧角色迁移不再生成偏好。启动、普通保存及其他目录操作不自动清理；旧偏好不参与执行或有效使用引用检查。

#### Scenario: F005-S04 一次性清理

- **WHEN** 用户使用原生子任务或处理旧分工偏好
- **THEN** 一次性清理：AUTO 页在该字段存在时显示“旧分工偏好已停用”卡片，可查看内容并预览清理，包括空对象。清理仅删除 auto.preferences，不删除旧 auto.main／roles、视觉设置、模型、别名或官方 Subagent 设置；不存在则提示无需清理。

#### Scenario: F005-S05 安全边界

- **WHEN** 用户使用原生子任务或处理旧分工偏好
- **THEN** 安全边界：预览／取消不写配置、不调用 LLM；有其他草稿先保存或放弃再预览。应用需明确选择整体清理，备份原始值及存在状态；恢复受现有版本检查约束，恢复后的偏好仍停用。清理完成卡片消失，页面仍可发现最近操作并恢复，恢复后卡片重新显示。

#### Scenario: F005-S06 本次验收

- **WHEN** 用户使用原生子任务或处理旧分工偏好
- **THEN** 本次验收：当前六个标签页（旧版五页验收口径已由来源页扩展）、官方配置可独立使用、旧路由未注册、不注入偏好；迁移和普通保存不丢旧数据且不再生成；清理取消／应用／恢复、冲突／失败回滚、未知字段和官方设置不变均覆盖。development 专用页面清理及恢复，并用专用会话验证原生子任务与 fork；未完成真实调用单列记录。
