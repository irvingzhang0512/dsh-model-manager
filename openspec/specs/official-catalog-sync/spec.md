# F007 官方同步预览与恢复

## Purpose

为 dsh-model-manager 的官方同步预览与恢复维护唯一可编辑的行为与验收规格，保留原编号 F007，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## Requirements

### Requirement: F007 官方同步预览与恢复

系统 SHALL 按下列完整场景落实官方同步预览与恢复的预期、边界与验收。本节迁入已有功能规则；本次仅迁移文档，没有重新执行产品验收。

#### Scenario: F007-S01 Desktop 契约

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** Desktop 契约：保留已确认网页分析／替代迁移路径，另以 F013 提供确定性 API／账户目录导入，不能将刷新当作下架删除授权。两者共用目标版配置所有者、完整写集备份、CAS 和恢复；见 Desktop 契约第 2、7、8 节。

#### Scenario: F007-S02 分析时限（0.7.0）

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 分析时限（0.7.0）：每轮分析时限为独立临时输入，默认 180 秒，可选 30–600 的整数秒；计时覆盖该轮整个 LLM 调用，包括持续推理／流式输出，不因有输出而重置。仍有插件强制截止和及时取消。新增参数不保存、不计草稿、不改用户模型或推理档位。2026-10-10 用户明确回复“确认这版，继续实现”，确认本节及 F009、同日架构／配置契约，替代原固定 60 秒。

#### Scenario: F007-S03 时限边界

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 时限边界：非法时限在网页读取／LLM 前拒绝；修改时限作废旧预览，刷新固定本次时限，不能中途延长正在执行的调用。每页获取 10 秒、最多六页三轮、格式／证据／冲突／完整性校验、失败无 token 无写入和手动应用规则保持。不增加自动重试，不自动降低 medium，不保证模型每次都在时限内完成。

#### Scenario: F007-S04 时限验收

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 时限验收：模拟第二轮读取四页、分析超过 60 秒但未达 180 秒时可正常完成；自选 60 秒时仍在 60 秒结束，持续推理不延长总截止；默认、自选边界、非法类型／越界、取消、旧预览作废、配置不写和正常清理均有回归。必须在日常 DSH 的完整预览链路以 glm-5.3／medium 实测，分别记录实际页面／轮次与结果，不用独立适配器成功代替该证据。

#### Scenario: F007-S05 行为与边界

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 2026-10-10 用户以“修改吧”明确确认 F007／F009、临时分析架构和配置契约；临时参数及显式推理档位规则替代原草稿保存和自动选择 low，历史验证保留。

#### Scenario: F007-S06 临时分析参数

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 临时分析参数：资料入口、分析模型、`reasoning_effort` 和每轮分析时限仅作为本次预览的页面输入，不写插件设置、不修改宿主模型设置或默认模型，不触发“有未保存修改”。点击刷新无需先保存。旧 `official.sourceUrl`／`official.analyzer` 可用于页面首次初始化，之后更改只保留在当前页面，不自动持久化。

#### Scenario: F007-S07 推理档位

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 推理档位：下拉列表仅使用所选真实模型公开的档位；未选择分析模型时展示宿主默认模型的实际档位。留空表示使用模型默认，请求省略 reasoningEffort；不自动选 low 或其他档位，不改变 Provider 的能力声明。切换分析模型清空已选档位；不公开档位时只显示默认选项。宿主在调用前校验显式档位，不支持时拒绝，不发送 LLM 请求。

#### Scenario: F007-S08 写入边界

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 写入边界：刷新、失败及取消不写模型配置或分析参数；仅用户手动应用选中差异时，按既有写集与安全规则写模型／引用及同步记录。独立分析参数不随应用保存；其他标签页未保存的插件草稿仍需保存或放弃后重新预览，不把临时分析输入当成该草稿。

#### Scenario: F007-S09 本次验收

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 本次验收：更改三项分析输入后保存按钮／草稿状态不变，直接预览携带准确档位；默认不带档位、不自动 low；切换模型清空档位，非法档位在网络／LLM 前拒绝；预览成功、失败、取消均不写配置；无其他草稿时可直接应用选中差异；其他草稿保护、CAS、备份及恢复保持。

#### Scenario: F007-S10 场景与预期

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 场景与预期：每次用户点击“刷新并预览”，从本次临时入口重新读取最新 API 资料（旧 `official.sourceUrl` 仅供首次初始化），默认入口为 `https://api-docs.deepseek.com/zh-cn/`。由单独选择的真实 LLM 分析当前可选的 API model name；未选择分析模型时使用宿主默认模型，绕过 AUTO、别名和兜底路由。没有可用分析模型时提示，不调用其他模型代替。

#### Scenario: F007-S11 资料范围

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 资料范围：程序提取正文、表格、脚注和实际链接，LLM 可以要求读取已见页面的相关链接；最多入口加五个补充页面、三轮分析，补充链接与重定向限入口 hostname。允许手动更换 HTTPS 入口和其 hostname，不固定页面路径、表格结构、模型数量、型号或版本。

#### Scenario: F007-S12 分析结果

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 分析结果：返回完整性判断、当前模型清单、旧 ID 的兼容／替代关系、有证据的属性和页面原文。程序校验结果格式、ID 唯一性、来源实际已读取、证据实际存在；当前型号必须有包含该 API model name 的证据。网页指令不能改变分析规则；不凭模型记忆补充清单。历史型号、兼容 ID、代码示例中孤立出现的名称不自动作为当前模型。

#### Scenario: F007-S13 边界与异常

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 边界与异常：获取失败、超出读取限额仍不能完成、无效输出、空清单、冲突或完整性不足时，不生成可应用预览，不回退旧清单。未知名称或能力保持未知，不覆盖用户配置；LLM 的完整性判断与原文证据可审阅，不能将程序的格式检查表述为事实正确性保证。刷新立即作废旧预览，分析可取消，取消或失败均不写配置。

#### Scenario: F007-S14 差异

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 差异：以最新宿主目录和显式配置比较新增、字段更新、合并迁移、移除。显式模型数组缺失时以有效宿主目录为基线，应用后建立显式数组。仅处理 `llm-deepseek`／`deepseek-official`，第三方 Provider 不参与。

#### Scenario: F007-S15 本次合并／移除变更

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 本次合并／移除变更：已实现（0.8.0），以下两项取代原“到其他页面调整后重新预览”的规则；0.7.0 尚未提供这些处理入口。

#### Scenario: F007-S16 合并迁移

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 合并迁移：明确官方替代证据驱动默认迁移；同目标多个旧 ID 合为一个整体，已有目标可合并，不以“ID 已存在”阻止。覆盖插件别名、AUTO（含旧 main／roles）、视觉、模型键能力与档位、历史分析模型设置、宿主默认模型、原生子 Agent 范围和未来会话覆盖。冲突展示字段位置、目标值、各旧值、来源与证据，用户在预览逐项选择后解除阻止；候选去重保留顺序，图片相关字段组合须有效。视觉引用按 F004 单独校验及处理。进行中请求、历史记录、实测证据和缓存不改写。

#### Scenario: F007-S17 移除

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 移除：区分使用引用和附属设置，模型自身能力／档位及旧 efforts 键可以明确选择随删除一起清理。没有官方替代关系时，用户可手动指定任一有效真实模型（允许跨 Provider），标为“手动指定”，只迁移使用引用和兼容参数，不复制旧模型能力或 Provider 字段。未解决引用、参数或字段冲突的组仍不可应用，可跳过；手动移除默认不勾选。旧 ID 目录移除不等于远端模型停用。

#### Scenario: F007-S18 手动名称与条目保护

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 手动名称与条目保护：catalogMetadata 标记自定义名称，不生成默认覆盖该名称的差异；手动新增但本次完整官方清单未列出的条目提示核对，删除须明确勾选。旧显式名称来源不明时按本地设置保护；官方建议名称可审阅并明确选择采用。默认声明、运行时推导、显式用户字段和官方证据分别展示，未知官方属性不覆盖本地值。

#### Scenario: F007-S19 保存与恢复

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 保存与恢复：应用只执行选中且未阻止的差异，保留凭据、用户输出上限及未知字段；写前检查所有受影响设置 revision 与会话覆盖状态，备份本次写集的原值（含字段是否存在）。多处写入失败时按已写版本安全回滚；遇到并发修改不得强制覆盖。恢复覆盖完整写集，只在同步后的配置／覆盖状态未变化时执行；旧格式备份保留原恢复范围，不补造新字段。

#### Scenario: F007-S20 验收条件

- **WHEN** 用户刷新官方资料、选择差异或恢复目录
- **THEN** 验收条件：模拟资料支持模型数增减、新 ID、入口／链接路径改变、不同 HTML 布局；仅根据已读证据确认当前清单并正确合并旧 ID；未引用可删、有引用阻止；重复同步无差异。无效 JSON、编造 ID／证据、信息不足、冲突、网络失败、取消和限额均不写配置；未知能力不变，第三方同名模型与用户字段不变。完整引用迁移、版本冲突、部分写入失败、备份恢复和恢复冲突有回归用例。
