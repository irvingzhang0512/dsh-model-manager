# F003 AUTO 主模型评估

## Purpose

为 dsh-model-manager 的AUTO 主模型评估维护唯一可编辑的行为与验收规格，保留原编号 F003，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## Requirements

### Requirement: F003 AUTO 主模型评估

系统 SHALL 按下列完整场景落实AUTO 主模型评估的预期、边界与验收。本节迁入已有功能规则；本次仅迁移文档，没有重新执行产品验收。

#### Scenario: F003-S01 Desktop 契约

- **WHEN** 用户选择 AUTO 并开始主任务
- **THEN** Desktop 契约：在三档执行模型基础上增加有序的任务类型／可选复杂度规则；首个匹配且可用规则优先，未匹配按复杂度向上兜底。只从已保存用户池选择；能力检查使用完整请求的宿主 Token 估算，评估器一次返回类型和复杂度，10 秒失败回退 general／normal，取消直接停止。规则／模型本轮固定，生成建议只改草稿；见 Desktop 契约第 5 节。

#### Scenario: F003-S02 行为与边界

- **WHEN** 用户选择 AUTO 并开始主任务
- **THEN** 图片候选资格只依据冻结宿主目录的 nativeImage，旧 models.*.capability.image 不再覆盖该结果；其余 AUTO 规则保持。原生图片未知不能当作支持。

#### Scenario: F003-S03 行为与边界

- **WHEN** 用户选择 AUTO 并开始主任务
- **THEN** AUTO 仍只评估主任务；停止分工偏好提示注入，不用旧 preferences 为子任务选模型。子任务不再次评估 AUTO，不继承主任务临时模型覆盖；fork 延续父模型和宿主参数继承规则。旧主模型与视觉兜底不随本次清理移除。

#### Scenario: F003-S04 本次验收

- **WHEN** 用户选择 AUTO 并开始主任务
- **THEN** 本次验收：即使存在历史偏好，系统提示也不包含分工建议；普通原生子任务的显式模型及推理档位不被插件覆盖；父任务使用 AUTO 时 fork 延续父任务已选执行模型，子任务不额外调用评估器。

#### Scenario: F003-S05 场景与预期

- **WHEN** 用户选择 AUTO 并开始主任务
- **THEN** 场景与预期：启用 AUTO 后对主任务按 simple／normal／complex 评估，结合上下文与能力选择模型档位；每轮复用评估结果。

#### Scenario: F003-S06 边界与异常

- **WHEN** 用户选择 AUTO 并开始主任务
- **THEN** 边界与异常：评估输入受限且不带图片内容，超时／失败回退正常路径；内部评估与子任务不递归触发；未启用不增加评估调用。

#### Scenario: F003-S07 验收条件

- **WHEN** 用户选择 AUTO 并开始主任务
- **THEN** 验收条件：工具循环不重复评估；所需能力不匹配时升级候选或明确失败；评估异常不阻塞正常请求。

### Requirement: F003-Desktop 5. AUTO 类型规则与复杂度（F003／F005／F006）

系统 SHALL 遵守已确认并实现的 Desktop 契约；本节替代对应旧平台接口与旧默认表述，不恢复已退役能力。

#### Scenario: F003-Desktop-S01 5. AUTO 类型规则与复杂度（F003／F005／F006）

- **WHEN** 用户选择 AUTO 并开始主任务
- **THEN** 满足以下完整契约：

- 任务类型固定 coding／writing／research／analysis／general，对应编码／写作／调研／分析／通用；复杂度仍是 simple／normal／complex。图片是能力条件，不强制成为独立任务类型。
- 用户手动配置评估模型、其真实推理档位、三档执行目标及有序规则。规则包括稳定 id、中文名称、启用、任务类型集合、可选复杂度集合、Selection；省略复杂度表示不限，空集合非法。
- 先对所有已配置目标做能力资格检查，使用宿主 TokenMeter 估算完整请求和输出预留，包含系统提示、工具、历史和图片；估算不是精确 Token 保证，不再以纯文本字符数冒充 Token。视觉辅助配置完整时，文本候选也可以处理图片任务。
- 评估器只读取最新任务及既有受限近期上下文，返回 taskType、grade、reason，不读图片像素、不调用工具、不执行任务。未配置或未启用 AUTO 不产生评估；评估只使用真实模型，不走 AUTO／别名。
- 总评估时限 10 秒，由插件执行绝对截止；解析失败、非正常终止、超时或迟到结果回退 general＋normal。用户取消直接停止，不作为评估失败继续执行。
- 按顺序采用首个类型／复杂度匹配且有合格候选的启用规则；匹配但不可用时继续下一规则。没有可用规则则从评估 grade 向 normal／complex 的更高档查找；没有兼容目标明确失败，不选择用户池外模型。
- 同一 session＋turn 仅评估一次，工具循环复用规则／档位与实际成功候选；规则修改不影响已开始轮次。记录任务分类、命中规则、逻辑入口、实际模型及回退理由，不记录完整提示词。
- “生成推荐”只返回三档和可选规则草稿及解释，可选同次建议评估模型；只引用真实已加载模型或已保存别名，不猜价格／性能。用户检查保存后才启用，不自动改变来源顺序或运行配置。
- 原生 Subagent 的任务拆分、工具和模型范围归宿主；不恢复旧固定角色或分工提示，不新增重复子 Agent 页。显式子模型与档位保持，子任务不二次评估 AUTO；fork 使用父任务实际执行模型。
